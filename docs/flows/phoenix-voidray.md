# 流派方案 · 凤凰 + 虚空（Stargate 空中变体）

> 优先级 B 级 · 预计改动量：小
> 社区出处：SpawningTool "Safe Default PvP Stargate Opener" 等星门开局；
> 中文社区小金毛「狂暴凤凰」对虫族打法。

## 流派定位

星门开局的空中变体：凤凰掌制空 + 虚空对重甲/建筑。定位是**天空体系的变体和反空军答案**，
而非独立主力流派——当对面（尤其虫族/神族）出空军时，给参谋长一个「以空制空」的选项。

- 坦率标注：凤凰一半价值在抬人（Graviton Beam，需要精准选目标施法），与 0-APM 架构相冲；
  本方案只用凤凰的**对空普攻**（机动性好、对轻甲空军加成），抬人留待将来写专属类。
- 虚空 ray 对重甲加成、充能普攻，a-move 基本够用（yml 已登记，`default` 起步）。

## 前置依赖

- P0（流派配置化）。与暴风舰/航母共用星门链，科技成本最低。

## 改动清单

1. **spawn 配方**（示意）：`PHOENIX 0.5 priority 0` + `VOIDRAY 0.5 priority 1`；
   对虫族可全凤凰（凤凰克飞龙/腐化都是轻甲……腐化是重甲，凤凰打不动——跑局实测配比）。
2. **科技链**：复用暴风舰流的星门链（不需要舰队航标，省 300/200——
   flow 块 `core_structures` 配 `GATEWAY → CYBERNETICSCORE → STARGATE` 即可）。
3. **combat class**：首版全 `default`；后续可写 `phoenix_offensive`
   （利用速度巡逻制空、不打地面、抬人），独立排期。
4. **升级**：空系攻防，与航母流共用配置。
5. **build_meta.md**：新增 `PhoenixVoid` 档案段——写明适用场景（对面空军多时）、
   写明「凤凰不抬人，别指望它打地面」。

## 验证

- 无头：对 Zerg（飞龙路线 AI）和对 Protoss AI 各几局。
- 实机：看凤凰制空效果（不抬人版本值多少分）、虚空充能输出节奏。

## 风险与调优点

- 不抬人的凤凰可能打不过成规模腐化/维京——若实测如此，本流派降级为「混编组件」
  （在其他流派里挂 20% 凤凰制空），不作为独立流派保留。
- 与航母流抢星门产能，混编时注意 spawn 优先级。
