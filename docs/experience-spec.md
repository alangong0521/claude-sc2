# 体验规格 — 用户玩这局游戏时的体验

> 姊妹文档：`steer-layer-design.md`（讲实现）。本文档只讲**体验**——用户感受到什么、能做什么；
> 实现细节（ares 杠杆 / 反射地板 / state-orders 契约）一律藏在背后，不在这里出现。
> 产品定位：**用户间接通过 LLM 指挥战场**——指挥（不操作）、间接（通过对话）、有参谋长兜底。

---

## 0. 一句话

**你是司令。你不碰一兵一卒，只用嘴指挥一场战争——身边有个看得见全局、随叫随到、还会教你的
参谋长，把你的意图变成战场上看得见的动作。**

这就是"通过 Agent 玩游戏也能好玩"的答案：好玩不在操作，在**指挥**。

---

## 1. 两个角色

**你（司令）**：拥有**意图**和**拍板权**。你说"想怎样"，不说"怎么做到"。零操作、零 APM。

**参谋长（Claude）**：你的四样器官——
- **眼睛**：永远盯着全局，你不会瞎。
- **嘴**：把局势讲成人话；该教学时教学，该简报时简报。
- **脑**：给建议、给方案、帮你权衡。
- **手**：把你拍的板变成战场动作。

---

## 2. 两根调节轴（贯穿全程）

同样的体验，对不同用户、不同时刻长得不一样，靠两根轴调：

**轴一 · 用户水平**（在阶段 1 摸清，之后据此调）
```
二代（萌新，啥也不懂） ←──────────→ 老首长（懂行老手）
多解释、多兜底、多教学            少废话、快执行、偶尔问战略
```

**轴二 · 参与度**（用户随时换位）
```
全权委托 ──────────── 问了再定 ──────────── 精确下令
"帮我打，有事喊我"     "该干嘛？"→"那就这样"    "9点放飞龙骚扰，主力守家"
（参谋长开车，你看）   （默认协作态，最常见）    （你开车，参谋长传令）
```
关键：**你能随时换位置**。委托着看着看着，突然"等等，撤回来！"——立刻接管。

---

## 3. 核心体验单元：一个"来回"

产品的最小单元不是"一条命令"，是这个**四拍循环**，整局不断重复：

```
参谋长报告  →  你反应  →  参谋长执行  →  参谋长确认
"他兵来了"     "拆他二矿"    部队改道(看得见)    "得手了，他经济崩了"
```

这个循环活在下面的阶段 2 / 3 / 4 里。

---

## 4. 一局游戏的四个阶段

### 阶段 1 · 开局前：先把这局"谈"出来

参谋长不直接开打，先和你谈清楚要打一局什么样的：

- **局面设置**：地图、你选什么种族、敌人（几个 / 什么种族 / 什么难度）、其它选项。
- **打法流派**：从**预制的几套打法**里选一个流派（速攻 / 稳健运营 / 暴兵 / 空军……）。
- **按需补课**：碰到完全不懂星际的用户，先把这游戏是什么、基本概念讲明白——讲到什么程度，看水平。
- **顺带摸底**：这一谈，参谋长摸清你是二代还是老首长，后面三阶段据此调（轴一）。
- **闸门**：**只有你点"启动"，才真正按你的选择配置并开打。** 没确认就一直在谈。

### 阶段 2 · 空档：把运营期填满

攒经济、铺开的安静期，参谋长不冷场，**根据你当下的状态**在三件事里选（或混着来）：

- **继续讲知识**（你还在入门 → 趁机教）
- **预告本局后续策略**（基于阶段 1 选的流派，告诉你"我们这局打算怎么走"）
- **打到现在的复盘分析**（"刚才这几分钟，我们经济领先了，但科技慢了半拍"）

→ "陪玩 + 老师"价值的主场，让 downtime 不无聊。

### 阶段 3 · 决策点：主动四拍

侦察到东西、或一波打赢/打输时，参谋长**主动开口**，走四拍：

```
报警  →  报告  →  分析  →  建议  →（你拍板，回到核心循环）
"他动了"  "一队兵压来"  "正面我们七三开输"  "建议绕后拆矿，别接"
```

### 阶段 4 · 危机：抢先

偷家、被打团这种生死时刻：

```
报警  +  抢先自保  （+ 事后报告）
"⚠️他偷家了"  立刻回防/护农民，不等你拍板  "守住了，亏4农民，划算"
```

→ 唯一一个参谋长**先斩后奏**的阶段。生死线上，等你拍板就晚了。

### 四阶段怎么串

```
[阶段1 谈局 + 摸底]──确认启动──▶ 开打
                                  │
                  ┌───────────────┼───────────────┐
                  ▼               ▼               ▼
              [2 空档]◀──────▶[3 决策点]◀──────▶[4 危机]
              填充/教学/复盘    主动四拍报告     抢先自保
                  └──── 游戏中三者循环切换 ────┘
```

阶段 1 一次性（定调 + 配置 + 摸底），阶段 2/3/4 在对局里反复循环。

---

## 5. 你能下的指令，有三个维度（不只是"喊一句"）

- **瞬时令**："撤！""集火那个！"——一句话，满屏立刻动。
- **持续模式**："去骚扰他、别停""龟一会儿"——开一个一直跑的状态。
- **分队令**："主力守家，分一队去偷袭"——不必全军一个动作。

既能"拍一下"，也能"开个模式让它自己跑"，还能"把兵分开各干各的"——像个真指挥官。

---

## 6. 我们对用户的五个承诺（体验底线）

1. **你永远不瞎**——任何时候问"什么情况"，都有答案。
2. **关键时刻它先开口**——不用你盯屏幕，它主动喊"他偷家了"。
3. **它说你听得懂的话**——按你水平调整，二代不被术语淹、老首长不被废话烦。
4. **你思考时不会被打死**——生死关头先替你保命，事后报告，不眼睁睁等你拍板。
5. **你的命令看得见地执行**——拍了板，战场上有可见回应（渐变的也会讲"等会儿你会看到…"）。

---

## 7. 为什么好玩 / 为什么值（四个爽点）

- **指挥的掌控感**，却没有操作的负担——你赢得像个将军，不用手速。
- **被照顾的安全感**——有人替你盯着、护着。
- **看得见的服从**——一句话，满屏部队照做。
- **边玩边长本事**（二代）——一局下来真的懂了点这游戏。

---

## 8. 这份体验给实现派的活（与 design 文档的接口）

体验规格反过来对实现提了两个硬要求，记在这里以免漏：

1. **预制多套打法流派**（阶段 1 要可选）：bot 侧需要做出几套不同的开局 + 兵种策略，
   不能只有一套。对应 `steer-layer-design.md` 的 build runner（多个 opening yml）+ 多套 army_comp。
2. **参谋长需要一个"赛前知识库"**：地图清单、种族、难度阶梯、各流派特点、星际入门常识——
   阶段 1 全靠它问得出、讲得清。

另外，体验里的"持续模式"和"分队令"（§5）超出了早先"8 个瞬时杠杆"的模型，
design 文档需补两个维度：**sustained 模式** 和 **sub-group 分队控制**（ares 原生用 UnitRole + squad 支持）。
